# Mythoi XML Examples

MYTHOI XML is a bespoke XML format suitable for capturing a particular view of the *narrative and rhetorical/prosodic structures* of epic and episodic poetry.

The primary hierarchy represented in MYTHOI is not in lines or line groupings, but rather categories that are depicted or represented only implicitly, if at all, in typography. The reader infers where the story pauses for the story-within-the-story, and resumes again. MYTHOI markup makes this structure explicit. 

There is NO CONNECTION between this format and any company or group engaged with generative AI.
